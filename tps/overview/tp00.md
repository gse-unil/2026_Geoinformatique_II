# Projet individuel

Analyse spatiale complète, de la question de recherche à la carte finale, publiée sur ton site web. Travail individuel, à sujet libre, réalisé en 4 étapes avec 2 rendus (50 % de la note finale). Les détails complets (calendrier, évaluation, critères) se trouvent sur **[Moodle]({{ MOODLE_URL }})**.

## Exigences en bref

- **Question de recherche** qui mobilise des données spatiales, avec une **carte** pour visualiser les résultats et les conclusions ; des données assez riches pour que le projet soit intéressant.
- **Chaîne de ≥ 5 traitements** couvrant les 3 types d'outils : préparation/sélection, combinaison de couches, analyse spatiale.
- **Un algorithme de régression, de classification ou une analyse statistique spatiale** pour répondre à la question.
- **≥ 3 jeux de données ouverts** (dont ≥ 1 vectoriel) ; données ouvertes, sauf cas exceptionnel à justifier.
- **Données organisées proprement**, en suivant le plan de l'année dernière : GeoPackage unique avec couches `src_` / `tmp_` / `hab_` / `ana_`, rasters en GeoTIFF, chaîne automatisée (Modeleur graphique `.model3` + notebook maître Python).
- **Palette d'outils élargie** : traitements SIG, mais aussi régression, classification, réduction de dimensionnalité, etc. Le plus simple et le plus approprié est le mieux.
- **Reproductibilité** : pas seulement du code ou un modèle qui tourne — les explications qui les accompagnent en font partie.
- **Remise sur site web** : portfolio (TP5) présentant le projet, le notebook maître et le rapport.
