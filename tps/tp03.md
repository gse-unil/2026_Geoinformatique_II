# TP 3 : Analyse spatiale vectorielle

Sur le cas d'étude de l'interface habitat-forêt (**WUI**) dans le canton de Berne, tu découvres les grandes familles d'outils de géotraitement vectoriel : **sélection et extraction**, **proximité** (zones tampons) et **superposition** (union, différence, intersection, regroupement). Tu construis ensuite ta première chaîne de traitements automatisée avec le **modeleur graphique** de QGIS (fichier `.model3`).

| Volet | Contenu |
|-------|---------|
| [TP3 QGIS](tp03-qgis.md) | Sélection/extraction, zones tampons, superposition, cas WUI, modeleur graphique |
| [TP3 Python](tp-py03.ipynb) | GeoPandas + Shapely : sélection, buffer, overlay (WUI) ; régression non-linéaire : polynômes, GLM, **GAM** (splines, lisseur spatial), validation croisée |
